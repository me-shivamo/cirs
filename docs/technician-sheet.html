Video kiosk technician sheet

The kiosk is a full-screen web page that plays 18 videos. Use the first option that works on this screen. The USB pen drive contains everything: the app, the videos, the showreel and these sheets.

A Android with Chrome (preferred)

  1. Open Chrome and go to the kiosk link: https://cirs-booth.pages.dev/
  2. Tap Download videos (about 1.3 GB). No Wi-Fi? Open the link once on a phone hotspot, then tap Load from USB stick → pen drive → CIRS-KIOSK/videos/hd → ⋮ Select all → Open.
  3. When it says all 18 are saved, tap Add to Home screen, then Start.
  4. Android settings: set the display sleep timeout to the maximum (or Developer options → Stay awake), lock landscape, set media volume, and turn on Do Not Disturb. Turn off the panel's own power-saving / OSD sleep timer.
  5. Optional lock: Settings → Security → App pinning, then pin Chrome or the CIRS Videos app.

B Android without Chrome, or to lock the screen: Fully Kiosk Browser

  1. Install Fully Kiosk Browser from the Play Store, or the APK from fully-kiosk.com.
  2. Start URL: the kiosk link above. Web Content Settings: Autoplay videos ON, JavaScript ON. Web Browsing Settings: Pull to refresh OFF.
  3. Device Management: Keep screen on ON, Launch on boot ON. Kiosk Mode needs a PLUS licence; without it, use App pinning.
  4. Then follow steps 2–3 of option A inside Fully Kiosk.

C/D Windows PC or laptop

  1. Copy CIRS-KIOSK from the pen drive to C:\CIRS-KIOSK.
  2. Double-click START-KIOSK.bat. It opens full screen and restarts the browser if it closes. Stop it with STOP-KIOSK.bat.
  3. To start automatically at power-on, run INSTALL-AUTOSTART.bat. This also disables sleep.
  4. Laptop + touch panel: connect HDMI and the USB touch cable. Press Win+P → Second screen only. If touches land on the wrong display: Control Panel → Tablet PC Settings → Setup → Touch input, then tap the panel.

F Touch not working: showreel

Play CIRS-Showreel.mp4 (pen drive root) in the panel's or TV's media player and set Repeat / Loop. All 18 videos play with title cards, about 64 minutes.

G Visitors' phones

The QR standee opens …/?visitor: the same topics, streamed to the phone.

Staff screen (status, self-test, fixes)

Hold “Keep Smiling” (top right) for 5 seconds, or press Ctrl+Shift+S on a keyboard. PIN 2026.

  • Run self-test: plays 1 second of every video and shows ✓/✗ for each one.
  • Video quality → Lite: use this if videos stutter on a slow screen. It needs the Lite copies, which are on the pen drive in videos/lite.
  • Mode → Loop only: plays the videos one after another and ignores touches. Use it if touch is unreliable.
  • Volume, Download / repair videos, Load from USB stick, Check for updates, Restart app.
  • Send a photo of this screen to the developer. It shows the device, storage and which videos are saved.

Behaviour (normal)

  • When nobody touches the screen for 90 seconds: a silent showreel starts. Any touch returns to the topics.
  • When a video is paused: it returns to the topics after 45 seconds.
  • When a video can't load: after about 8 seconds, it shows a message and goes back.
  • Every few hours, when idle: the page refreshes itself.
