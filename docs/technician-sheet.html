Video kiosk technician sheet

The kiosk is a full-screen web page that plays 19 videos and works without internet once set up. Use the first plan that works on this screen. The pen drive (CIRS-KIOSK folder) contains everything: the app, the videos, the showreel and these sheets.

Plan A · Windows screen or laptop (pen drive, no internet)

  1. Plug in the pen drive, open CIRS-KIOSK, double-click START-KIOSK.bat. It opens full screen and reopens the browser if someone closes it. To stop: Alt+Tab → STOP-KIOSK.bat.
  2. Laptop for the whole event: copy CIRS-KIOSK to C:\CIRS-KIOSK and run INSTALL-AUTOSTART.bat from there. The kiosk then starts at power-on, and sleep is switched off.
  3. Laptop + touch panel: connect HDMI and the USB touch cable. Press Win+P → Second screen only. If touches land on the wrong display: Control Panel → Tablet PC Settings → Setup → Touch input, then tap the panel.

Plan B · Android with Chrome (link)

  1. Open Chrome and go to the kiosk link: https://me-shivamo.github.io/cirs/
  2. Tap Download videos (720p, about 400 MB). For full HD, or with no Wi-Fi, open the link once (phone hotspot is enough), tap Load from USB stick → pen drive → CIRS-KIOSK/videos/hd → ⋮ Select all → Open.
  3. When it says all 19 are saved, tap Add to Home screen (if shown), then Start.
  4. Android settings: display sleep timeout to the maximum (or Developer options → Stay awake), lock landscape, set media volume, Do Not Disturb on. Turn off the panel's own power-saving / OSD sleep timer.
  5. Optional lock: Settings → Security → App pinning, then pin Chrome or the CIRS Videos app.

Android without Chrome, or to lock the screen fully: Fully Kiosk Browser

  1. Install Fully Kiosk Browser from the Play Store, or the APK from fully-kiosk.com.
  2. Start URL: the kiosk link above. Web Content Settings: Autoplay videos ON, JavaScript ON. Web Browsing Settings: Pull to refresh OFF. Device Management: Keep screen on ON, Launch on boot ON.
  3. Then follow Plan B steps 2–3 inside Fully Kiosk. (Its Kiosk Mode needs a PLUS licence; without it, use App pinning.)

Touch not working: showreel

Play CIRS-Showreel.mp4 (pen drive, inside CIRS-KIOSK) in the panel's or TV's media player and set Repeat / Loop. All 19 videos play with title cards, about 67 minutes.

Visitors' phones

The QR standee opens …/?visitor: the same topics, streamed to the phone.

Preparing a pen drive

Copy the whole CIRS-KIOSK folder (2.2 GB) onto a pen drive of 8 GB or more. Use exFAT or FAT32 (Android screens often cannot read NTFS). Keep the folder name. Test once on a laptop with START-KIOSK.bat.

Staff screen (status, self-test, fixes)

Hold “Keep Smiling” (top right) for 5 seconds, or press Ctrl+Shift+S on a keyboard. PIN 2026.

  • Run self-test: plays 1 second of every video and shows ✓/✗ for each one.
  • Video quality → Lite: use this if videos stutter on a slow screen. It needs the Lite copies, which are on the pen drive in videos/lite.
  • Mode → Loop only: plays the videos one after another and ignores touches. Use it if touch is unreliable.
  • Volume, Download / repair videos, Load from USB stick, Check for updates, Restart app.
  • Send a photo of this screen to the developer. It shows the device, storage and which videos are saved.

Behaviour (normal)

  • When nobody touches the screen for 90 seconds: a silent showreel starts. Any touch returns to the topics.
  • When a video is paused: it returns to the topics after 45 seconds.
  • When a video can't load: after about 8 seconds, it shows a message and goes back.
  • Every few hours, when idle: the page refreshes itself.
