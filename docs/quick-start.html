Touch screen Quick Start

Set up each of the two screens once, on the setup day. About 20 minutes per screen. Try Plan A first; if it does not work, use Plan B.

Carry: the CIRS pen drive  ·  a phone with hotspot data  ·  this card  ·  the Technician sheet

PLAN A

Pen drive

Windows screen or laptop · 2 minutes · no internet needed
1

Plug the pen drive into the screen, or into the laptop connected to the screen.

2

Open the CIRS-KIOSK folder and double-click START-KIOSK.

3

The topics open full screen. Done ✓  (To close it: press Alt + Tab, then double-click STOP-KIOSK.)

→ Android screen, or nothing happens? Use Plan B.

PLAN B

Link in Chrome

Android screen · 15–20 minutes
OPEN IN CHROME ON THE SCREEN
me-shivamo.github.io/cirs

Scan the code with the screen's camera, or type the address in Chrome.

1

Tap Download videos. Needs Wi-Fi or a phone hotspot, about 400 MB, 10–15 minutes. Wait until it says “All 19 videos are saved”. If the Wi-Fi drops, it continues by itself.

No internet? Tap Load from USB stick → pen drive → CIRS-KIOSK › videos › hd → ⋮ Select all → Open.

2

Tap Add to Home screen (if you see it), then Start. An orange CIRS Videos icon appears on the screen's home page. No internet is needed after this.

3

Check: tap 2–3 topics. Each video plays full screen and goes back to the topics by itself when it ends. Home goes back at any time.

CIRS BOOTH · TOUCH SCREENS

Every day, and if something goes wrong

Every morning

  • Switch the screen on. Plan A: double-click START-KIOSK (a laptop set to start automatically opens it by itself). Plan B: tap the orange CIRS Videos icon.
  • When nobody touches the screen for 90 seconds, the videos play silently one after another. This is normal: any touch brings back the topics.

the screen shows something else (a web page, the tablet's home screen)

Tap the orange CIRS Videos icon (Plan A: double-click START-KIOSK).

a video does not play, or the screen is frozen

Switch the screen off and on again, then open it as in “Every morning”.

the download is stuck, or there is no Wi-Fi

Connect the screen to a phone hotspot (the download continues by itself), or use Load from USB stick as in Plan B, step 1.

neither Plan A nor Plan B works

Give the Technician sheet and the pen drive to the screen company's technician.

touch does not work at all

Ask the technician to play CIRS-Showreel.mp4 (on the pen drive) on repeat. All 19 videos play one after another.
